# PUNTO 1: ¿Qué es y qué problema resuelve? (Dev 1)

## Tu Objetivo
Desarrollar la pantalla que responde directamente al **Punto 1** del pitch:
> *'Baqui es un sistema que da información para prevenir daños frente al fenómeno de El Niño. Te dice cómo está el camino rural, para que decidas si salir sin tener que ir hasta ahí a mirar.'*

## Qué debe mostrar tu View:
1. Vista interactiva de caminos rurales estilo PUNA.
2. Demostración del Radar SAR: botón para alternar entre satélite óptico (tapado por nubes) y Radar SAR (atraviesa nubes y resalta el camino bajo agua).
3. Indicador de estado del camino (Ruta Provincial 13): 🔴 CORTADO (64.2% anegamiento).
